## 🎯 Mission Brief

<div align="center">

I'm building **TITANIUM-6** — a 7-layer hierarchical intrusion detection pipeline that refuses to hide its own failures.

While most NIDS papers report F1 = 0.99 and stop at the confusion matrix, TITANIUM-6 reports two negative results as first-class findings:

- 🔬 **5% adversarial perturbation collapses F1 from 0.9079 → 0.0058**
- 🔬 **Cross-dataset transfer drops F1 from 0.9077 → 0.1970**

I document these because deployment reality matters more than benchmark theater.
