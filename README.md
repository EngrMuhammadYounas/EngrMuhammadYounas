## 🚀 Flagship Project — TITANIUM-6

**A 7-layer ML-based Network Intrusion Detection System (NIDS)** that detects known and zero-day attacks with explainability and automated response.

### 📊 Headline Results

| Layer | Function | Metric |
|-------|----------|--------|
| **L1** | Feature Engineering | 85 features · 16.2M flows |
| **L2** | Binary Gatekeeper (XGBoost) | **F1 = 0.9077** · **AUC = 0.9841** · FPR = 2.79% |
| **L3** | Family Classifier (LightGBM) | **Macro-F1 = 0.9188** (11 families) |
| **L4** | Zero-Day Anomaly Detector | **85.9% combined DR** (IF + Autoencoder) |
| **L5** | SOAR Response Engine | 584,279 MITRE-mapped decisions |
| **L6** | Explainability | TreeSHAP + Counterfactual + NL summaries |
| **L7** | Production API | Sub-15 ms P95 · FastAPI |

### 🔬 Honest Limitations (Documented in Paper)

- Cross-dataset F1 drops to **0.1970** on CIC-IDS2017 — reported transparently.
- Adversarial fragility: 5% perturbation collapses F1 — documented as a negative result.
- XSS/SQLi zero-day DR: 22.6% — payload-level attacks need DPI.
