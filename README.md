## 🔬 Flagship · TITANIUM-6

A **7-layer hierarchical intrusion detection pipeline** built on 16.2M network flows.

**It refuses to hide its own failures.**

| Layer | Role | Result |
|:-----:|------|--------|
| **L2** | Binary Gatekeeper *(XGBoost)* | F1 = 0.9101 · FPR = 2.68% |
| **L3** | 11-Family Classifier *(LightGBM)* | Macro-F1 = 0.9182 |
| **L4** | Zero-Day Anomaly *(IsoForest + Autoencoder)* | 87.8% DR |
| **L5** | SOAR Response *(MITRE ATT&CK)* | 582K decisions |
| **L7** | Production API *(FastAPI)* | 11.9 ms P95 |

**Two negative results reported as first-class findings:**

- 🔻 5% adversarial perturbation collapses L2 F1: **0.9079 → 0.0058**
- 🔻 Cross-dataset transfer to CIC-IDS2017: **0.9077 → 0.1970**
